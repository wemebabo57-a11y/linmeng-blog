# 版本索引

本目录存放林梦博客各版本的完整源码，**每个版本一个文件夹**。

每个版本文件夹都是一个可以直接部署的站点目录：把它里面的全部内容上传到网站根目录即可运行，具体步骤见该版本文件夹内的 `README.md`。

## 版本列表

| 版本 | 目录 | 说明 |
|------|------|------|
| v2.4.2 | [`v2.4.2/`](v2.4.2/) | 完整可部署源码，含该版本的详细说明 |

历史版本同样保留在本目录中，按需自行选择。

> 文件夹名称即版本号，与程序内 `includes/config.php` 中的 `LM_VERSION` 常量一致。

## 该选哪个版本

- **全新搭建** —— 选版本号最大的那个
- **升级已有站点** —— 选比当前更高的版本，并先阅读该版本 `README.md` 中的升级说明
- **找回旧版本** —— 直接进入对应版本号的文件夹

## 目录说明

```
src/
├── README.md          # 本文件：版本索引
└── <版本号>/          # 某个版本的完整源码
    ├── README.md      #   该版本的部署说明与功能列表
    ├── index.php      #   站点入口
    ├── admin/         #   后台管理
    ├── api/           #   前端接口
    ├── assets/        #   静态资源
    ├── includes/      #   核心库
    ├── setup/         #   安装向导（安装后需删除）
    └── template/      #   前台模板
```

> ⚠️ `src/` 本身不是网站目录，请勿将 `src/` 整个上传到服务器，应上传其中某个版本文件夹里面的内容。
