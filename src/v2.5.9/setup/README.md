# 安装向导使用说明

访问 `http(s)://你的域名/setup/` 即可启动安装向导，向导会引导你完成以下配置：

1. **数据库连接**：主机、端口、库名、用户名、密码（库不存在会自动创建）。
2. **站点信息**：网站标题、描述、关键词、站长昵称、联系邮箱、站点地址等。
3. **管理员账号**：用户名、邮箱、密码（密码至少 8 位，bcrypt 加密存储）。
4. **备份恢复**：可选导入后台导出的 ZIP，恢复数据库和文章。`lm_` 表前缀会转换为 `app_`。
5. **头像与背景**：头像、Logo、Favicon、背景图，支持填写直链或本地上传。

安装完成后向导会自动：

- 建库建表（`setup/schema.sql`，表前缀 `app_`）；
- 写入站点默认设置（含头像、背景、管理员邮箱等）；
- 生成 `.env`（含随机 `SECRET_KEY`）与 `includes/config_installed.php` 安装标记。

> **安全提示**：安装完成后请立即删除服务器上的 `setup/` 目录，避免重复安装。
> 后续改头像 / 背景 / 管理员账号，请登录后台「网站设置」与「用户管理」。
