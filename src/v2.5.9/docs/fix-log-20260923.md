> 原逻辑在 GitHub 邮箱已验证时直接绑定到同邮箱的本站账号；但本站邮箱从未验证且 `profile.php` 允许任意修改，
> 攻击者可预先占位邮箱，再把他人 GitHub 身份绑上去。现改为**提示先用密码登录，再在「个人中心」主动绑定**
> （`github-callback.php`）。GitHub 邮箱仍可用于新建账号，仅不再用于自动绑定。

## 二、安全加固

- `Security::getClientIp()`：`CF-Connecting-IP` 改为**先校验 TCP 直连对端（`REMOTE_ADDR`）是否属 Cloudflare 官方网段**
  才采信（新增 `isCloudflareIp()`），不再单纯依赖 `APP_TRUST_PROXY` 开关。
  漏判会让源站把所有访客看成同一个 CF 边缘 IP，导致限流、登录锁定与匿名 CSRF 令牌在整条边缘节点上被共享。
- `X-Forwarded-For` 仍在 `APP_TRUST_PROXY` 开启时才采信，未变。

## 三、新增：SMTP 邮件提醒

- 新增 `includes/Mailer.php`（类 `AppMailer`）：纯 PHP socket 实现，无第三方依赖，
  支持 SSL(465) / STARTTLS(587) / 明文(25)。
- 后台「设置 → 邮件提醒」可配置：`smtp_enabled`、`smtp_host`、`smtp_port`、`smtp_encryption`、
  `smtp_username`、`smtp_password`、`smtp_from_email`、`smtp_from_name`、`smtp_skip_verify`、
  `notify_admin_email`、`notify_link_apply`、`notify_comment_reply`，并支持「保存并发送测试邮件」。
- 已接入：友链申请通知（`link-apply.php`）、评论回复通知（`api/comment-reply.php`）、文章页（`article.php`）。
- `smtp_host` 支持直接粘贴 `smtp.qq.com:465`、`ssl://smtp.qq.com` 这类写法，自动拆出端口。

## 五、修复：镜像模块缺失函数（历史遗留缺陷）

`mirror.php` 与 `admin/mirror.php` 调用的 4 个函数此前**未定义**，访问镜像页必然 500。
本次补齐于 `includes/functions.php`：

- `ensureMirrorTables()` — 首次访问后台时按 `setup/schema.sql` 自建 `app_mirror_category` / `app_mirror_software`。
- `getMirrorCategories($onlyVisible = false)`
- `getMirrorSoftwares($categoryId = 0, $onlyVisible = false)`
- `getAllMirrorSoftwares()` — 后台列表，关联出 `category_name`。

同时发现后台软件列表引用了 `views` 字段，而 `setup/schema.sql` 中该表**无此列**，已补
`` `views` INT UNSIGNED NOT NULL DEFAULT 0 `` 到建表语句与 `ensureMirrorTables()`。
