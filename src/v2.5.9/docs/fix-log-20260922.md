# 修复记录（2026-09-22）

本轮按代码审查结论修 P0/P1，只补必要防护，未加定时发布、找回密码等新产品功能。
所有改动的 PHP 文件已用 `php -l` 校验。

## 缺陷修复

### 1. 首页首次访问 302 可能污染 CDN / 爬虫收录

`index.php` 原先对所有无 `app_guide_seen` 的请求 302 到 `/guide.php`，且发生在缓存头之前。

- 仅普通浏览器的无查询 GET 才跳转；爬虫、空 UA、HEAD、带 search/category/page 的请求不跳。
- 302 显式输出 `Cache-Control: private, no-store`。

### 2. 前台文章数把草稿算进去

`getArticleCount()` 改为 `WHERE status = 'published'`。

### 3. HTTPS 判断不统一

新增 `Security::isHttps()`：仅在 `APP_TRUST_PROXY` 开启时才采信 `X-Forwarded-Proto`。
`app_is_https()`、HSTS、访客 Cookie 的 `secure` 均走同一逻辑。

### 4. 文章评论防护弱于留言板

文章评论补齐：Turnstile（复用留言板开关）、PRG 303、60 秒内容去重。
去重抽成 `app_is_recent_comment_duplicate()`，留言板一并改用。
后台回复接口长度校验改为 `mb_strlen`。

### 5. Sitemap 缓存不随发文失效

`app_purge_page_cache()` 同时删除 `cache/sitemap.xml`。

### 6. 音乐代理无限流

`music-proxy.php` 增加每 IP 每分钟 20 次限流，以及 8MB 响应体积上限。

### 7. 访问日志只写不清理

`api/visit.php` 写入 PV 时按 1/200 概率删除 30 天前明细。

### 8. 搜索无限流

首页搜索每 IP 每分钟最多 30 次，超出时当次搜索词清空。
